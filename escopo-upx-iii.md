# Escopo do Projeto – Bike Energy

## Objetivo
Desenvolver uma aplicação web para registrar sessões de treino, armazenar energia gerada, calcular créditos/descontos e apresentar essas informações a alunos e gestores.

## Será desenvolvido
- aplicação web
- autenticação
- perfis aluno/gestor
- cadastro de bicicletas
- sessões
- registro/simulação de energia
- histórico
- créditos/descontos
- painéis
- relatórios simples
- testes e documentação

## Não será desenvolvido
- fabricação da bicicleta
- construção do gerador
- circuitos e sensores
- inversores/baterias
- instalação elétrica
- certificação do hardware
- cobrança financeira real
- app mobile nativo

## Dependência externa
O hardware será fornecido por parceiro especializado.

## Estratégia do MVP
O sistema terá uma entrada/simulação de energia para demonstrar o fluxo completo sem o equipamento físico.
